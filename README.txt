DE 6 WEB1013 - WEBSITE FPT POLYTECHNIC

1. Mở file index.html để chạy website.
2. Đổi chữ "TÊN SINH VIÊN" ở cuối trang thành tên của bạn.
3. Website đã có:
   - Header, logo, ô tìm kiếm và nút TÌM KIẾM.
   - Menu 5 mục, hover và link.
   - Banner theo mẫu.
   - Khu vực TIN TỨC HỌC TẬP theo bố cục đề.
   - Link ở các tiêu đề tin.
   - Hover ảnh có đổ bóng màu đen #000.
   - Form tìm kiếm và validate khi bỏ trống.
   - Responsive cơ bản.

Thang điểm đề: 3 + 2 + 2 + 1 + 2.
